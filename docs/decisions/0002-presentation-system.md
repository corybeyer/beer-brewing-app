# ADR-0002: Shared design system

Status: Proposed

## Decision
Use semantic CSS tokens, approved typography and icons, reusable accessible components, and consistent responsive layouts. Put generic visual primitives under web/src/design-system/, and brewery-specific screen logic under web/src/features/.

## Requirements
Maintain accessible contrast, visible focus, large mobile touch targets, statuses not conveyed by color alone, and clear temperature units/freshness. Visual change reviews should compare screenshots/story examples.
