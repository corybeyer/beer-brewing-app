# Requirements

- [Product scope](product-scope.md): equipment direction, user journey, intended capabilities, and delivery boundaries.
- [Acceptance scenarios and validation rules](acceptance-scenarios.md): stable AC IDs, transactional integrity, timer/confirmation behavior, and measurement semantics.

Future feature specifications should describe actor, intent, acceptance criteria, error behavior, telemetry freshness, data retention, and confirmation requirements. Implementation work should cite the relevant specification and add tests for its acceptance criteria.
