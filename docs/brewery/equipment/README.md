# Equipment baseline

The selected mash tun is an insulated cooler. The mash does not recirculate; HERMS and RIMS are outside this design. HLT and boil kettle, manual physical actions, and immersion chilling are the current direction. Sparging/transfer routes and sensor selection remain open.

See [product scope](../../requirements/product-scope.md) and [open decisions](../../plan/open-decisions.md). Reference wireframes are not verified plumbing or hardware instructions.
