## Adding images

Use descriptive filenames, preferably including the screen ID, viewport, and date, for example:

- `ui-01-brew-day-phone-2026-11-07.png`
- `ui-02-recipe-steps-desktop-2026-11-07.png`

When sharing an image for a task, reference its repository path and describe the behavior or visual detail it should guide. Include its source and whether it shows an existing implementation, a proposed design, or a problem to fix. Screenshots are guidance; they do not establish implemented behavior or approve architectural decisions.

Remove credentials, personal information, and production configuration before adding images.

The original supplied wireframes are linked above; [design/wireframes](../design/wireframes/README.md) maintains their interpretation and known corrections. See [screen specifications](../design/screens.md) for screen IDs.
