# Brewery UI design principles

- Consistency: no feature-local color/font/spacing palettes; use semantic design tokens.
- Readability: large temperatures and timers, tabular numbers, clearly visible units.
- Outdoor ergonomics: phone and tablet responsive layouts, generous touch targets, high contrast.
- Trustworthy telemetry: display measured-at time and stale/offline/anomalous state; never silently substitute values.
- Safety: recommendations are not equipment controls; brewer confirms manual stage changes.
- Accessibility: semantic controls, keyboard navigation, color-independent alerts, reduced motion.
- Asset policy: use approved icon library and versioned/licensed assets; no bundled proprietary font files.
