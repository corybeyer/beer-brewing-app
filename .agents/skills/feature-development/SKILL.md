# Feature development
1. Read root and scoped AGENTS.md plus relevant requirements.
2. State acceptance criteria and identify domain, API, UI, and persistence impact.
3. Implement a narrow vertical slice without unrelated refactors.
4. Reuse contracts and existing shared components.
5. Add unit and integration tests; include failure and stale-data cases.
6. Validate with repository checks and summarize behavioral changes.
