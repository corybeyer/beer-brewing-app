# Design system
1. Read web/AGENTS.md and docs/design/.
2. Reuse semantic CSS tokens from web/src/design-system/tokens/ before introducing values.
3. Prefer shared accessible controls to feature-specific versions.
4. Specify interaction states, focus visibility, touch targets, and responsive behavior.
5. Add usage examples and visual/a11y tests when changing shared components.
6. Do not add unlicensed fonts or images to the repository.
